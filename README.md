## 🚀 About The Project

**PuneTurfCricket — HITSIX Sports** is a modern, responsive web-based cricket tournament registration platform designed to make tournament participation simple and convenient.

Users can register as an individual player, register their complete team, participate in free registration activities, or submit sponsorship requests — all through a single platform.

The platform is designed to work smoothly across **mobile, tablet and desktop devices**.

---

## ✨ Key Features

| 🏏 Feature | Description |
|---|---|
| 👤 Individual Registration | Players can register individually |
| 👥 Team Registration | Complete teams can register together |
| 🆓 Free Registration | Free registration option available |
| 🤝 Sponsor Registration | Companies/brands can submit sponsorship requests |
| 💳 Online Payment | Razorpay payment links for paid registrations |
| 📄 Document Upload | Aadhaar/document upload support |
| 📊 Admin Dashboard | View and manage registration data |
| 🔎 Search & Filter | Quickly search and filter registrations |
| 📈 Registration Tracking | Track registration and payment information |
| 📱 Responsive UI | Works on mobile, tablet and desktop |
| ☁️ Cloud Database | Registration data stored in MongoDB Atlas |
| ⚡ REST API | Frontend communicates with Node.js backend |

---

## 🎯 Registration Types

### 👤 Individual Player
Players can register individually for the tournament by submitting their required details and completing the applicable payment process.

### 👥 Team Registration
Teams can register with multiple players and provide complete team information through the registration form.

### 🆓 Free Registration
Users can participate in free registration activities without a paid registration process.

### 🤝 Sponsor Registration
Businesses and brands can submit sponsorship information and select their preferred sponsorship option.
